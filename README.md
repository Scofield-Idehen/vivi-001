# The Grange Estate site

A side project, kept on its own branch with no link to V-01's code. Every push to this branch publishes
`site/` to its own Firebase Hosting site, https://grange-estate.web.app.

The photos come from the public Airbnb listing and are not yet approved by the owner, so the site tells
search engines not to list it. Keep the link private until the owner approves them.
